# 1. 영상처리 개요

## 1.2 영상처리의 수준

### 저수준 영상처리
> 영상 데이터의 처리 결과가 영상일 경우
(좁은 의미의 영상처리)

- 영상획득
- 영상향상
- 영상복원
- 변환처리
- 영상압축


### 고수준 영상처리
> 영상 데이터의 처리 결과가 영상의 특성들인 경우
(컴퓨터 비전)

- 영상분할
- 영상표현
- 영상인식


## 1.3 영상처리의 역사
>영상의 형성은 광원으로부터 물체에 비친 빛이 카메라 센서를 통해 영상을 형성한다.

## 1.4 영상처리 관련 분야

영상 $\rarr$ 서술 : 컴퓨터 비전

서술 $\rarr$ 영상 : 컴퓨터 그래픽스

## 1.5 영상의 형성 과정
> 영상은 위치값과 밝기값을 가진 일정한 수의 화소들의 모임으로 정의한다.


영상 f(x,y) 는 조명의 세기 i(x,y)와 반사계수 r(x,y)의 곱으로 나타난다.
- i(x,y) : 물체에 비친 조명의 세기
- r(x,y) : 반사 계수로서 0과 1 사이의 값
- sampling $\rarr$ quantization 과정을 거쳐서 최종적인 디지털 영상이 형성됨
    - sampling : 카메라 해상도에 해당하는 유한개의 화소의 수만큼 입력 값을 취한다. (M X N)
    - quantization : 어떤 위치의 표본화된 화소값이 128,345라고 해도 8비트 디지털 화소로 나타내는 경우에는 128로만 나타남. 즉, 표본화된 화소의 값을 디지털 화소로 표현하는 단계

## 1.6 디지털 영상의 표현과 영상 처리
- 표본화와 양자화를 거친 영상은 일정 수의 화소(pixel)들의 집합인 M X N 크기의 영상으로 표현
- 화소수가 M X N개, 각 화소의 양자화 수준에 따라 밝기값의 수준(gray-level)이 정해짐.
    - 만일, k 비트로 양자화 되었다면, 밝기값의 수준 $L = 2^k$
- 필요한 저장 공간 S = M X N X k 비트
